## Reading the auctions { #reading-auctions }

| Stage | Who bids |
| --- | --- |
| **Introduce** | Opener's opening bid |
| **Explore** | Responder's first response |
| **Clarify** | Opener's first rebid |
| **Decide** | Responder's second call |

Parentheses mark opponents' calls. In examples between partners, assume the opponents pass unless shown. **HCP** means high-card points. **Dummy points** are support values used when a fit is known.
