## Link from Markdown { #link-from-markdown }

For a lesson in this project's `docs/lessons/` folder, write:

```markdown
[Review Stayman](../bidding/notrump.md#stayman)
```

For a lesson on another site, open the published reference section and copy the full URL including the text after `#`. A GitHub Pages project URL includes the repository name before the reference path.

To link back from the reference, add a **Related lesson** link below the applicable section once the lesson exists. A section heading such as `## Stayman { #stayman }` keeps its published anchor when the visible heading changes.
